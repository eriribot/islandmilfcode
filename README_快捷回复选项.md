```

                     测试 3-5 轮 → 稳定？
                       ├─ 是 → 保持当前配置 ✓
                       └─ 否 → 进一步简化到最简版（50字）
```

## 🔧 故障排查流程

```
问题：选项没有显示
  ↓
1. 检查 AI 回复中是否有 <options> 标签
   ├─ 没有 → 提示词未生效
   │          → 检查世界书条目是否启用
   │          → 检查 order 优先级
   │          → 尝试简化提示词
   │
   └─ 有 → 检查格式是否正确
            ├─ 格式错误 → 参考 DeepSeek 优化指南
            └─ 格式正确 → 检查前端代码（少见）

问题：AI 频繁掉格式
  ↓
1. 确认使用的模型
   ├─ DeepSeek V4 → 使用专项优化方案
   │                 参考：DeepSeek_V4_格式优化指南.md
   │
   └─ 其他模型 → 简化提示词
                  参考：快捷回复选项_简化提示词.md
  ↓
2. 调整 API 参数
   - Temperature: 0.3
   - Stop Words: ["</options>"]
  ↓
3. 添加 Few-Shot 范例
  ↓
4. 如仍无效 → 考虑更换模型
```

## 📊 功能概览

### 已实现功能

- ✅ 从 `<options>` 标签自动提取选项
- ✅ 椭圆形按钮，居中显示
- ✅ 千恋万花视觉小说风格
- ✅ 点击选项自动发送
- ✅ 支持流式和非流式模式
- ✅ 响应式布局（2x2 网格）
- ✅ 悬停动画效果

### 技术栈

- **前端框架**：原生 TypeScript
- **样式**：CSS3（渐变、阴影、动画）
- **解析**：正则表达式
- **渲染**：HTML 模板字符串
- **事件**：原生 DOM 事件监听
