# Unit Registry

## 目的

机体登记表用于让 SRW Harness 知道每个项目或模块能做什么、不能做什么、怎么验证、什么时候必须请求驾驶员批准。

未登记的机体不能直接出击。AI 可以侦察它，但不能把它纳入跨项目协议。

## 登记模板

```text
机体名：
定位：
驾驶员可见界面：
主要输入：
主要输出：
权威状态：
关键不变量：
常见失败模式：
可直接执行动作：
需批准动作：
验证方式：
关联武器：
```

## 主机体：islandmilfcode

机体名：`islandmilfcode`

定位：

- 手帐式楼层阅读 / 续写界面模块。
- 当前 SRW Harness 第一主机体。
- 负责楼层阅读、续写、回溯、重新生成、变量读取、状态驱动 UI。

驾驶员可见界面：

- 手帐阅读器。
- 楼层正文区。
- 右键楼层菜单。
- 手机与记忆库入口。
- 当前 Codex 线程中的工程驾驶舱。

主要输入：

- 宿主聊天楼层。
- `stat_data`。
- MVU 或酒馆变量 API。
- 用户输入。
- 世界书控制器输出。
- 记忆库摘要与事件。

主要输出：

- 新楼层或重生成楼层。
- 状态更新。
- 变量写回。
- UI 渲染。
- 提示词拼装结果。
- 记忆库提交。

权威状态：

- 宿主消息楼层是剧情记录权威。
- `stat_data` 是结构化状态主入口。
- 记忆库表是长期事实和事件索引。

关键不变量：

- `index.ts` 只做入口装配、初始化、生命周期绑定和渲染调度。
- 页面层不得直接操作底层变量接口。
- `prompt` / `message-format` 不混入 DOM 操作或变量写回。
- `render` 不直接读取底层变量，不直接触发生成请求。
- 重新生成成功清空 draft，失败保留 draft。
- `lastSummarizedIndex` 只增不减，除非超过实际消息总数。

常见失败模式：

- 核心业务继续堆进 `index.ts`。
- 提示词、变量、渲染互相串层。
- 角色名硬编码扩散到数据结构。
- 摘要索引回退导致旧消息污染 prompt。
- 世界书角色卡被关键词误触发。
- 重生成失败后 draft 丢失。

可直接执行动作：

- 读文档、读接口、定位函数。
- 新增说明文档。
- 小范围修正文档或测试。
- 运行类型检查、构建或关键词检查。

需批准动作：

- 改提示词主结构。
- 改变量 schema。
- 改记忆库提交时机。
- 改楼层生成和回溯行为。
- 改角色路线推进规则。
- 大范围拆分 `index.ts`。

验证方式：

- `rg` 检查职责边界和关键词。
- TypeScript 类型检查。
- 构建。
- 最小楼层交互测试。
- 重生成成功 / 失败路径测试。
- 摘要索引污染回归测试。

关联武器：

- 模块分层。
- 消息污染防线。
- 世界书裁剪。
- 驾驶舱批准门。

## 驾驶舱候选：webgame-ui

机体名：`webgame-ui`

定位：

- 可视化驾驶舱或游戏式操作界面。
- 适合承载更明确的按钮、状态面板、模式切换和战斗反馈。

驾驶员可见界面：

- Web UI。
- 游戏面板。
- 状态仪表。
- 操作按钮。

主要输入：

- 当前任务状态。
- 角色、剧情、变量和楼层摘要。
- 驾驶员操作。
- bridgeapi 返回结果。

主要输出：

- 驾驶员操作意图。
- UI 状态。
- 可发送给宿主或后端的动作请求。
- 可视化反馈。

权威状态：

- UI 本地状态不是剧情权威。
- 权威状态必须回到宿主楼层、变量、数据库或母舰登记文档。

关键不变量：

- UI 只能显示和提交动作，不能独自宣称剧情完成。
- 高风险按钮必须有确认或批准门。
- 失败状态必须可见。
- 不能用花哨视觉掩盖桥接失败。

常见失败模式：

- UI 自己维护一套与宿主不一致的状态。
- 按钮触发后没有真实楼层或数据库结果。
- 自动连发导致驾驶员失去手操节奏。
- 状态面板只显示成功，不显示失败原因。

可直接执行动作：

- 原型文档。
- 静态 UI 草图。
- 非权威状态面板。
- 本地视觉检查。

需批准动作：

- 接入真实生成链路。
- 接入真实数据库写入。
- 改同层卡主交互。
- 引入自动连发或批处理。

验证方式：

- 浏览器截图。
- 控制台错误检查。
- 按钮到宿主动作的链路检查。
- 失败态显示检查。

关联武器：

- 驾驶舱批准门。
- 同层桥接。
- 战斗记录。

## 接驳舱：bridgeapi_shujuku

机体名：`bridgeapi_shujuku`

定位：

- 母舰、UI 和酒馆宿主真实楼层之间的接驳舱。
- 负责让同层卡操作进入原生规划、数据库更新、世界书扫描和助手生成链路。

驾驶员可见界面：

- 同层卡 UI。
- Codex 任务线程。
- 宿主聊天楼层。
- 调试日志或桥接结果提示。

主要输入：

- UI 操作。
- 驾驶员批准。
- 宿主聊天上下文。
- 世界书扫描结果。
- qrf_plot / ACU / shujuku 规划链路。

主要输出：

- hidden real user floor。
- hidden real assistant floor。
- `/trigger await=true` 结果。
- 数据库更新。
- 生成后的宿主楼层变化。

权威状态：

- `SillyTavern.getContext().chat` 或等价宿主真实聊天状态是权威。
- hidden real floors 是原生链路承载，不是装饰。
- iframe 内部状态只能作为驾驶舱显示，不能作为最终事实。

关键不变量：

- 同层桥接必须经过真实宿主消息。
- 世界书扫描不能被 UI 内部缓存替代。
- 数据库更新必须能追溯到真实楼层或明确动作。
- 桥接失败必须暴露给驾驶员。

常见失败模式：

- iframe 状态看似成功，但宿主没有真实楼层。
- hidden floor 缺失，导致原生规划不触发。
- 正则深度不对，世界书或数据库链路断开。
- 生成未 await 完成就更新 UI 成功态。
- 静默吞掉 trigger 失败。

可直接执行动作：

- 画流程图。
- 检查事件名和调用顺序。
- 写桥接测试计划。
- 新增非执行说明文档。

需批准动作：

- 改 hidden floor 策略。
- 改 `/trigger await=true` 调用方式。
- 改数据库写入时机。
- 改正则深度。
- 改世界书扫描入口。

验证方式：

- 最小真实楼层往返。
- hidden user / assistant floor 可见性检查。
- 世界书扫描命中检查。
- 数据库更新检查。
- 失败态 UI 检查。

关联武器：

- 同层桥接真实楼层。
- 驾驶舱批准门。
- 战斗记录。
